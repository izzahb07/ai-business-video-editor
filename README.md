# AI Business Video Studio

A professional video editor that runs in **Safari on iPhone** (and any modern desktop browser).
Editing, colour, graphics, captions rendering, smart-edit analysis and MP4 export all happen **on your device** — your footage is never uploaded.

**Open it:** https://izzahb07.github.io/ai-business-video-editor/ (Safari → Share → *Add to Home Screen* for an app icon)

## ✨ The fastest way: Auto Edit
Import your clips → tap **✨ Let AI edit it for me** (or the **AI** tab) → pick a style → type what the video is about → **✨ Auto edit my video**.
It removes silences, adds captions, colour, transitions, music that dips when you talk, whoosh effects, and a hook + call to action — as one change you can undo with one tap. Each step shows ✓ done, – skipped (with the reason) or ✕ failed.
For the best captions and AI-written hooks, connect the optional AI server (below); without it, captions use the on-device speech model and the hook comes from a template.

## 📱 How to use it on your iPhone

**Layout:** video preview at the top → timeline in the middle → tool panel → tool tabs at the bottom. Tap **More space** above the panel to hide the timeline when you need room.

### 1. Import and arrange (Edit tab)
1. Tap **Import videos** and pick clips/photos from *Photo Library*.
2. **Scroll the timeline** left/right to move the playhead (the white line). **Pinch** (or −/+) to zoom.
3. **Tap a clip** to select it (yellow border):
   - drag its **yellow edges** to trim, or use the *Trim* sliders / *Start here* / *End here*;
   - **drag the selected clip** left/right to change its order;
   - **Split** cuts the clip at the playhead;
   - *Frame* lets you zoom, move, rotate, flip and crop;
   - *Transition into this clip* adds a transition at the cut (or *Apply to all cuts*);
   - *Clip sound*: mute, volume, **Voice enhance**, **Reduce background noise**.
4. **↶ / ↷** undo and redo anything.

### 2. Captions (Captions tab)
1. Choose the language (*Detect*, *English* or *Bahasa Melayu*).
2. Engine: **On this device** (free, private; downloads a speech model once, ~40–80 MB) or **My AI server** (most accurate — see "AI server" below).
3. Tap **Generate captions**. (The first on-device run downloads the model — stay on Wi-Fi.)
4. Pick a **template**, then fine-tune font, size, colours, animation and position. Drag captions up/down on the video to move them.
5. Fix words in **Edit captions**; tap a line to nudge its timing or tap words to highlight them. **Highlight key words** marks numbers and important words automatically.
6. Captions are burned into the exported video. **Download .srt** gives a separate subtitle file.

### 3. Graphics (Graphics tab)
- Tap **Text, Title, Hook, Lower third, Call to action** or a **shape** — it appears at the playhead.
- **Drag it on the video** to move it; **pinch** to resize. Edit the words, font and colours in the panel. Wrap a word in `*stars*` to highlight it.
- *Animation*: choose how it appears/disappears and an optional loop.
- *Keyframes*: tap **Animate with keyframes**, move the playhead, then drag or adjust — it animates between keyframes.
- **Logo / image** and **Picture-in-picture** pick a file from Photos/Files. **Intro / Outro card** adds a ready-made title card.

### 4. Colour (Colour tab)
Select a clip (or put the playhead on it) → tap a **preset** → fine-tune with the sliders. **Before / after** shows a split view (preview only). **Import .cube LUT** from the Files app. **Apply to all clips** copies the look.

### 5. Audio (Audio tab)
- ▶ previews a sound; **＋ Add** places music from the start or an effect at the playhead.
- **Whoosh on transitions** / **Pop on graphics** place effects exactly on those moments.
- Tap a music/SFX bar on the timeline to change volume, fades, loop, ducking ("Lower when someone speaks") and timing.

### 6. AI (AI tab)
- **Analyse my video** → review suggestions → **Accept** or **Reject** each (or *Remove all silences*). Every change can be undone.
- **Hooks & structure**: pick your goal, describe the video (facts only), tap **Generate 10 hooks**. Tap **Use as hook text** to put one in the first 3 seconds. Lines under "Check before posting" are claims you must verify.

### 7. Export
**Export** (top right) → choose resolution, frame rate, quality and audio → **Export MP4**. Keep Safari open with the screen on. When it says **"Export complete and verified"**, tap **Save to Photos / Share → Save Video**.

**If something goes wrong:** tap **ⓘ** for the device check. Try 720p or Low bitrate for long videos, close other apps, keep Safari in front. iOS 16.4+ is required. For the most accurate colours, turn off *Settings → Camera → Record Video → HDR Video*.

## AI server (optional) — what needs an API key

| Feature | Needs | Notes |
|---|---|---|
| Everything in Edit, Colour, Graphics, Audio, Smart editing, Export | Nothing | Runs on your device |
| On-device captions | Nothing (downloads a public Whisper model once from Hugging Face) | Private, free |
| Cloud captions | Your server + OpenAI (or Groq) key | ≈ US$0.006/min (OpenAI whisper-1) |
| AI hooks & structure | Your server + Anthropic key | ≈ US$0.05–0.15 per generation |

Keys are **never** put in the app. They live as encrypted secrets in a small Cloudflare Worker you deploy from GitHub (free tier). Setup from your iPhone: **[server/README.md](server/README.md)**. The app always asks before sending audio or text, and never uploads video.

## Publishing the app (GitHub Pages)
1. Merge the development branch into `main` (Pull requests → New → Create → Merge).
2. Settings → Pages → Source: **GitHub Actions** (one time).
3. Actions → "Build and deploy video editor to GitHub Pages" → wait for the green tick.

> ⚠️ **Only one workflow should publish the site:** `.github/workflows/deploy.yml` ("Build and deploy video editor to GitHub Pages").
> Do **not** add GitHub's suggested "Jekyll" or "Static HTML" Pages workflows. They publish the raw source code instead of the built app, and the site shows a blank page.
> If the site is ever blank: open **Actions**, select "Build and deploy video editor to GitHub Pages", tap **Run workflow** on `main`.

## Honest limitations
- Tested in Chromium (desktop and iPhone-sized) — **not yet on a physical iPhone**. Safari uses the same WebCodecs/WebGL/Web Audio APIs; please report anything that misbehaves.
- On-device captions could not be tested here (the test environment can't download the speech model). Cloud captions were tested end-to-end against the real server code with a simulated provider.
- Transitions happen at each side of the cut (fade through black, flash, zoom punch, whip, blur); overlapping cross-dissolves aren't available yet.
- "Reduce background noise" is a noise gate (quietens hiss between words), not machine-learning noise removal.
- Clip speed changes (slow motion / speed-up) and keyframes on clips (as opposed to graphics) aren't available yet.
- Clip sound has its own track and controls but can't be dragged separately from its video.
- Very long videos: the MP4 is assembled in memory; the app warns above ~450 MB.
- Smart-edit scores (strongest moment, clip order, pacing) are measured from sound and pictures — they're rule-based, not an AI that "understands" the content.

## For developers
```bash
npm install
npm run dev          # local dev server
npm test             # unit tests (timeline, store, captions)
npm run build
npm run e2e          # end-to-end: real test videos → app → export → ffprobe/ffmpeg checks (Phase 1 + all studio modules)
cd server && npm test
```

The studio suite (`tests/e2e/studio.mjs`) drives the UI in an iPhone-sized browser and checks every module **in the exported MP4**: trim/split/rotate/transition/reorder pixels and timing; captions burned in, synced after trims, SRT; grade, LUT and before/after; graphic animation, keyframes, logo, PiP; music ducking, SFX, fades; silence removal and the AI hook round-trip (against the real server code); 60 fps/4K/audio-bitrate exports; autosave restore.

| Path | What it does |
|---|---|
| `src/engine/render.ts` | **The** frame renderer used by preview and export (clip → transitions → GPU grade → graphics → captions) |
| `src/engine/grade.ts` | WebGL2 colour grading shader, `.cube` parser, presets |
| `src/engine/overlays.ts`, `text.ts` | Motion graphics, animation & keyframes, text layout |
| `src/engine/captions.ts` | Caption sync to edits, karaoke/animated drawing, SRT |
| `src/engine/audio.ts` | Audio graph shared by preview & export (voice processing, music, SFX, ducking, fades), audio analysis |
| `src/lib/export/exporter.ts` | WebCodecs H.264/AAC export with per-layer decode streams and file verification |
| `src/lib/analysis/` | On-device smart-edit analysis (silence, scenes, repeats, scoring) |
| `src/lib/transcribe/` | Whisper worker (on-device) and cloud transcription client |
| `src/lib/soundLibrary.ts` | Built-in synthesised music & SFX |
| `src/components/` | UI (Timeline, panels, sheets) |
| `server/` | Optional Cloudflare Worker (transcription + Claude hooks) |
